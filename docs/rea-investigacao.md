## Procedimento permitido

1. Determinar objetivo e escopo; registrar autorização, versão e data.
2. Observar páginas públicas ou instâncias de demonstração cujo acesso tenha sido autorizado.
3. Registrar navegação, campos visíveis, mensagens, estados e fluxos com evidências datadas.
4. Classificar cada constatação como observação verificada, hipótese ou lacuna.
5. Especificar critérios de aceite para implementação independente.
6. Não copiar arquivos privados, código, identidade visual exclusiva ou dados de usuários; não contornar autenticação ou licenciamento.

Prompt recomendado: "Observe somente páginas públicas ou uma instância de teste autorizada. Documente campos, validações, estados, jornadas, regras inferidas e lacunas. Separe evidência de hipótese e proponha requisitos originais sem copiar código ou dados proprietários."
