# Orbe Público

Plataforma independente de gestão pública municipal — projeto em desenvolvimento.

> Status: MVP demonstrativo. Não homologado para produção, prestação de contas, contabilidade ou folha de pagamento.

A implementação inicial está sendo preparada na branch `feat/mvp-inicial` para revisão antes da integração à `main`.

O sistema não é afiliado à Memory Informática e não utiliza código ou ativos proprietários da empresa.

Documentação técnica e funcionalidades serão entregues no pull request inicial.
